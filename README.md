# Trillion OS Security Software

**Trillion OS Security Software** is an independent security-focused operating platform developed by **TrillionAi Tech Limited** on top of the official upstream **seL4 microkernel**.

## Foundation

This project uses the official upstream seL4 project as its kernel foundation.

seL4 remains an independent open-source project with its own governance, licensing, trademarks, verification work, and release process.

Trillion-owned software is developed separately above the seL4 kernel boundary.

## Current Status

Active development.

The repository currently establishes and verifies the pinned upstream seL4 foundation used by this project.

No claim is made that the complete Trillion OS Security Software platform is formally verified, independently certified, or production-ready unless and until supporting evidence exists for the exact configuration and scope concerned.

## Security

This public repository does not document proprietary security mechanisms, internal policy logic, hardening methods, privileged implementation details, private threat models, key-management details, or other confidential defensive information.

Security-sensitive implementation details are intentionally kept out of public documentation.
